# 6.3 Update Profile – Request Email Change

Base URL:
'https://devops.juaracoding.com/kelompok2/api/v1/'

---

## Overview

This endpoint allows an authenticated user to request an email change.

The request may trigger an email verification process depending on backend implementation.

This is a protected endpoint and requires a valid access token.

---

## Endpoint

PUT /profile

---

## Headers

Authorization: Bearer <accessToken>
Content-Type: application/json

---

## Request Body

```json
{
  "fullName": "Elviana Victoria",
  "email": "elvianavictoria2@example.com"
}

| Field    | Type   | Required | Description                  |
| -------- | ------ | -------- | ---------------------------- |
| fullName | string | Yes      | Current or updated full name |
| email    | string | Yes      | New email address            |

success response:
{
  "status": "success",
  "message": "Email change request submitted",
  "data": {
    "id": 1,
    "fullName": "Elviana Victoria",
    "email": "elvianavictoria2@example.com",
    "role": "USER"
  }
}

error response:
{
  "status": "error",
  "message": "Email already in use"
}

authorized response:
{
  "status": "error",
  "message": "Unauthorized"
}
