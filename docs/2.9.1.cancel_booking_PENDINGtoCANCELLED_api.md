# 9.1 Cancel Booking - Pending to Cancelled [POSITIVE]

**Method:** `PUT`
**Endpoint:** `https://devops.juaracoding.com/kelompok2/api/v1/booking/{{bookingCode}}/status`

**Description:** Cancel booking

**Request Body:**
```json
{
  "status": 0,
  "cancellationReason": "User requested cancellation"
}
```

**Response:**
```json
{
    "detail": "Method 'PUT' is not supported.",
    "instance": "/api/v1/booking/status",
    "status": 405,
    "title": "Method Not Allowed"
}
```
