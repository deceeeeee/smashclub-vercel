# 1.3 Check Availability Invalid Court ID (Negative)

**Method:** `POST`
**Endpoint:** `https://devops.juaracoding.com/kelompok2/api/v1/booking/availability/courts`

## Headers

* `Content-Type: application/json`

## Request Body

```json
{
  "date": "{{date}}",
  "courtId": "{{invalid_court_id}}"
}
```

## Response
```json
{
    "path": "/api/v1/booking/availability/courts",
    "data": "",
    "success": false,
    "errorCode": "BOOK_002",
    "message": "Court tidak ditemukan",
    "status": 400,
    "timestamp": "2026-02-19T12:36:32.732929789Z"
}
```
**Status Code:** `404 Not Found`

### Validation (Postman Tests)

* Response status must be 404
* `response.data` must be an object
* `response.data.message` should contain "Court not found"
