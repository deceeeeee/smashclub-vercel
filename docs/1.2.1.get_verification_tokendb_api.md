`https://devops.juaracoding.com/kelompok2/api/v1/auth`

## 2.1 Get Verification Token from DB (Testing Only)

**Endpoint:** `GET /test/get-verification-token`

**Description:** 
Retrieves the email verification token from the database for testing purposes only.  
⚠️ This endpoint should NOT be available in production.

---

### Query Parameters

| Parameter | Type   | Required | Description |
|-----------|--------|----------|------------|
| email     | string | ✅ Yes   | User email address |
