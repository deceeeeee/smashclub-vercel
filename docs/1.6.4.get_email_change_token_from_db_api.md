# 6.4 Get Email Change Token from DB (Testing Only)

Base URL:
'https://devops.juaracoding.com/kelompok2/api/v1/auth'

---

## Overview

This endpoint retrieves the email change token directly from the database.

⚠ This endpoint is for testing purposes only.
It should NOT be used in production.

Used to simulate email verification flow during development.

---

## Endpoint

GET /test/get-email-change-token

---

## Query Parameters

| Parameter | Type   | Required | Description         |
|-----------|--------|----------|---------------------|
| userId    | number | Yes      | ID of the user      |

---

## Example Request

GET /test/get-email-change-token?userId=1

---

## Success Response (200)

```json
{
    "detail": "No static resource api/v1/test/get-email-change-token.",
    "instance": "/api/v1/test/get-email-change-token",
    "status": 404,

}

error response:
{
  "status": "error",
  "message": "User not found"
}
