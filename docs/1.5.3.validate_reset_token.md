# 5.3 Validate Reset Token

Base URL:
https://devops.juaracoding.com/kelompok2/api/v1/auth

---

## Overview

This endpoint validates whether a reset password token is valid or expired.

It is used before allowing the user to set a new password.

If the token is valid → frontend should display Reset Password form.

If the token is invalid or expired → frontend should show an error page.

---

## Endpoint

GET /validate-reset-token

---

## Query Parameters

| Parameter | Type   | Required | Description               |
|-----------|--------|----------|---------------------------|
| token     | string | Yes      | Reset password token UUID |

---

## Example Request

GET /validate-reset-token?token=275620e2-0cb8-4fdb-b30c-9df96faa6e7a

---
