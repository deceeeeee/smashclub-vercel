# 2.1 Get Available Coaches (Positive)

**Method:** `GET`
**Endpoint:** `https://devops.juaracoding.com/kelompok2/api/v1/booking/availability/coaches`

---

## Headers
*None*

## Query Parameters

* `date={{date}}`
* `startTime={{startTime}}`
* `endTime={{endTime}}`

## Success Response
{
    "path": "/api/v1/booking/availability/courts",
    "data": "",
    "success": false,
    "errorCode": "BOOK_002",
    "message": "Court tidak ditemukan",
    "status": 400,
    "timestamp": "2026-02-19T12:36:32.732929789Z"
}

**Status Code:** `200 OK`

### Validation (Postman Tests)

* Response status must be 200
* `response.data` must be an array
* If data exists, save:

  * `coachId = response.data[0].id`
  * `coachName = response.data[0].coachName`

---

## Example Test Script

```javascript
pm.test('Status code is 200', function() {
    pm.response.to.have.status(200);
});

pm.test('Response has coaches array', function() {
    const response = pm.response.json();
    pm.expect(response.data).to.be.an('array');
});

if (pm.response.code === 200) {
    const response = pm.response.json();
    if (response.data && response.data.length > 0) {
        pm.environment.set('coachId', response.data[0].id);
        pm.environment.set('coachName', response.data[0].coachName);
        console.log('✅ Coach ID saved: ' + response.data[0].id);
    }
}
```

---

## Notes

* Retrieves available coaches within a specified date and time range.
* Environment variables `{{date}}`, `{{startTime}}`, and `{{endTime}}` are required.
