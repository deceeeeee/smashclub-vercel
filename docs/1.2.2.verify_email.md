# Email Verification API Documentation

## Base URL
`https://devops.juaracoding.com/kelompok2/api/v1/auth`

---

## 2.2 Verify Email

**Endpoint:** `GET /verify-email`

**Description:** 
Verifies the email verification token from the database for testing purposes only.  
⚠️ This endpoint should NOT be available in production.

example request:
GET /auth/verify-email?token=abc123xyz456

success response:
{
    "data": {
        "verifiedAt": "2026-02-25T21:17:38.602666786",
        "userId": "82dfcb65-e062-4e98-bacf-e056ed79ba26",
        "email": "micdece69@gmail.com"
    },
    "success": true,
    "message": "Email berhasil diverifikasi",
    "status": 200,
    "timestamp": "2026-02-25T14:17:38.602831112Z"
}

invalid token response:
{
    "success": false,
    "data": "",
    "path": ""
    "error": "Invalid or expired token",
    "message": "Verification token is invalid or has expired",
    "timestamp": "2026-02-25T14:17:38.602831112Z"
}
