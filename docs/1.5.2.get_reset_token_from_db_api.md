# Password Reset API Documentation

## Base URL
`https://devops.juaracoding.com/kelompok2/api/v1/auth`

---

## 5.2 Get Reset Token from DB (Testing Only)

**Endpoint:** `GET /validate-reset-token`

**Description:** 
Retrieves the password reset token from the database for change password.

⚠️ This endpoint must NOT be available in production.

---

### Query Parameters

| Parameter | Type   | Required | Description |
|-----------|--------|----------|------------|
| token     | string | ✅ Yes   | Token for reset password |

---

### Example Request
GET /validate-reset-token


---
