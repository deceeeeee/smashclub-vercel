# 6.3 Create Booking - Start Time After End Time [NEGATIVE]

**Method:** `POST`
**Endpoint:** `https://devops.juaracoding.com/kelompok2/api/v1/booking`

**Description:** Create booking with start time after end time

**Request Body:**
```json
{
  "courtId": {{courtId}},
  "bookingDate": "{{date}}",
  "startTime": "11:00:00",
  "endTime": "09:00:00"
}
```

**Response:**
```json
{
    "path": "/api/v1/booking",
    "data": "",
    "success": false,
    "errorCode": "X01001",
    "message": "Unauthenticated",
    "status": 401,
    "timestamp": "2026-02-19T18:56:26.408369146Z"
}
```
