# Session Management API Documentation

## Base URL
`https://devops.juaracoding.com/kelompok2/api/v1/auth`

---

## 4.2 Check Session (Invalid Token)

**Endpoint:** `GET /check-session`

**Description:**
Tests error handling when an invalid, malformed, or expired token is used to check session status. This endpoint helps verify that the API properly rejects unauthorized requests.

---

### Headers
Authorization: Bearer {invalid_expired_or_malformed_token}

### Request
GET /check-session

### Error Response - Invalid Token
```json
{
    "success": false,
    "error": "Invalid token",
    "message": "The provided token is invalid or malformed"
}

error response expired token:
{
    "success": false,
    "error": "Token expired",
    "message": "Your session has expired. Please login again"
}

error response no token:
{
    "success": false,
    "error": "Unauthorized",
    "message": "No token provided"
}

error response wrong signature:
{
    "success": false,
    "error": "Invalid token signature",
    "message": "Token verification failed"
}
