## 6.8 Cancel Pending Email Change

**Endpoint:** `POST /cancel-email-change`

**Description:**
Cancels a pending email change request before it has been verified. This allows users to abort the email update process if they change their mind or if the verification email hasn't arrived.

---

### Headers
Authorization: Bearer {access_token}

### Request
POST /cancel-email-change


### Success Response
```json
{
    "success": true,
    "message": "Email change request cancelled successfully",
    "data": {
        "currentEmail": "elvianavictoria@example.com",
        "status": "no_pending_change"
    }
}

error response
```json
{
    "success": false,
    "error": "No pending email change",
    "message": "There is no email change request to cancel"
}

error unauthorized response
```json
{
    "success": false,
    "error": "Unauthorized",
    "message": "Invalid or expired token"
}

error respone too late to cancel:
```json
{
    "success": false,
    "error": "Cannot cancel",
    "message": "Email change already verified or expired"
}
```
