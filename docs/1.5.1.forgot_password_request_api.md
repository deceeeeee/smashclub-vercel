# Forgot Password Flow API Documentation

## Base URL
`https://devops.juaracoding.com/kelompok2/api/v1/auth`

---

## 5.1 Forgot Password Request

**Endpoint:** `POST /forgot-password`

**Description:**
Initiates the password reset process by sending a password reset link to the user's email address. For security reasons, the API returns the same response whether the email exists or not.

---

### Request (application/json)
```json
{
    "email": "elvianavictoria@example.com"
}

success response:
{
    "success": true,
    "message": "If your email is registered, you will receive a password reset link",
    "data": {
        "resetCooldown": 60,
        "expiresIn": 3600
    }
}

success respone (Email Not Found - Same Response for Security):
{
    "success": true,
    "message": "If your email is registered, you will receive a password reset link",
    "data": {
        "resetCooldown": 60,
        "expiresIn": 3600
    }
}

error response invalid email format:
{
    "success": false,
    "error": "Validation failed",
    "message": "Please provide a valid email address"
}

error response missing email:
{
    "success": false,
    "error": "Email required",
    "message": "Email address is required"
}

error response too many requests:
{
    "success": false,
    "error": "Too many requests",
    "message": "Please wait 60 minutes before requesting another reset",
    "data": {
        "waitTimeMinutes": 60
    }
}



Endpoint	        |Method	    |Description
/reset-password     |POST	    |Complete password reset with token
/verify-reset-token |GET	    |Validate reset token before showing form
