# 4.2.1 Wallet Balance API

**Method:** `GET`
**Endpoint:** `https://devops.juaracoding.com/kelompok2/api/v1/wallet/balance`

**Description:** Get wallet balance

**Response:**
```json
{
    "data": {
        "balance": 1000000.00
    },
    "success": true,
    "message": "Wallet balance found!",
    "status": 200,
    "timestamp": "2026-02-23T12:34:00.403127493Z"
}
```
