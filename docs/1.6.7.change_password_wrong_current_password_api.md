# 6.7 Change Password – Wrong Current Password (Error Scenario)

Base URL:
'https://devops.juaracoding.com/kelompok2/api/v1/auth'

---

## Overview

This is an error scenario of:

POST /profile/change-password

It occurs when the provided currentPassword is incorrect.

---

## Endpoint

POST /profile/change-password

---

## Headers

Authorization: Bearer <accessToken>
Content-Type: application/json

---

## Example Request

```json
{
  "currentPassword": "WrongPassword",
  "newPassword": "NewPassword456",
  "confirmPassword": "NewPassword456"
}

error response:
{
  "status": "error",
  "message": "Current password is incorrect"
}
