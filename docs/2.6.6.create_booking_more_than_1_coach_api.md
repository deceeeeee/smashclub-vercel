# 6.6 Create Booking - More Than 1 Coach [NEGATIVE]

**Method:** `POST`
**Endpoint:** `https://devops.juaracoding.com/kelompok2/api/v1/booking`

**Description:** Create booking with more than 1 coach

**Request Body:**
```json
{
  "courtId": {{courtId}},
  "bookingDate": "{{date}}",
  "startTime": "{{startTime}}",
  "endTime": "{{endTime}}",
  "coaches": [
    {
      "coachId": {{coachId}},
      "durationHours": 2
    },
    {
      "coachId": 2,
      "durationHours": 2
    }
  ]
}
```

**Response:**
```json
{
    "path": "/api/v1/booking",
    "data": "",
    "success": false,
    "errorCode": "X01001",
    "message": "Unauthenticated",
    "status": 401,
    "timestamp": "2026-02-19T19:08:13.489883533Z"
}
```
