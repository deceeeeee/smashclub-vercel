# 5.4 Reset Password

Base URL:
https://devops.juaracoding.com/kelompok2/api/v1/auth/reset-password

---

## Overview

This endpoint is used to reset the user's password using a valid reset token.

It must only be called after the reset token has been validated.

---

## Endpoint

POST /auth/reset-password

---

## Headers

Content-Type: application/json

---

## Request Body

```json
{
    "path": "/api/v1/auth/reset-password",
    "data": "",
    "success": false,
    "errorCode": "AUTH_011",
    "message": "Token reset tidak valid",
    "status": 400,
    "timestamp": "2026-02-19T07:49:54.926738438Z"
}

success response:
{
  "status": "success",
  "message": "Password successfully reset"
}

error response:
{
  "status": "error",
  "message": "Invalid or expired token"
}
