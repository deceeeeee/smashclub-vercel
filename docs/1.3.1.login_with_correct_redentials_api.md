# Authentication API Documentation

## Base URL
`https://devops.juaracoding.com/kelompok2/api/v1/auth/login`

---

## 3.1 Login with Correct Credentials

**Endpoint:** `POST /login`

**Description:** 
Authenticates a user using valid email and password credentials.

---

### Request (application/json)
```json
{
    "email": "elvianavictoria@example.com",
    "password": "Password123"
}

success response:
{
    "data": {
        "requiresOtp": true,

        "email": "victoriaelviana@gmail.com"

    "success": true,
