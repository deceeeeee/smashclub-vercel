# 6.4 Create Booking - Date in the Past [NEGATIVE]

**Method:** `POST`
**Endpoint:** `https://devops.juaracoding.com/kelompok2/api/v1/booking`

**Description:** Create booking with date in the past

**Request Body:**
```json
{
  "courtId": {{courtId}},
  "bookingDate": "2025-01-01",
  "startTime": "{{startTime}}",
  "endTime": "{{endTime}}"
}
```

**Response:**
```json
{
    "path": "/api/v1/booking",
    "data": "",
    "success": false,
    "errorCode": "X01001",
    "message": "Unauthenticated",
    "status": 401,
    "timestamp": "2026-02-19T19:01:51.993536705Z"
}
```
