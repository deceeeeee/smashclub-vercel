## 1. Court Availability

### 1.1 Get All Courts (Positive)

**Method:** `GET`
**Endpoint:** `https://devops.juaracoding.com/kelompok2/api/v1/booking/courts`

**Status Code:** `200 OK`

**Validation (Postman Tests):**

* Response status must be 200
* `response.data` must be an array
* If data exists, save:

  * `courtId = response.data[0].id`
  * `courtName = response.data[0].courtName`

### Example Test Script

```javascript
pm.test('Status code is 200', function() {
    pm.response.to.have.status(200);
});

pm.test('Response has courts array', function() {
    const response = pm.response.json();
    pm.expect(response.data).to.be.an('array');
});

if (pm.response.code === 200) {
    const response = pm.response.json();
    if (response.data && response.data.length > 0) {
        pm.environment.set('courtId', response.data[0].id);
        pm.environment.set('courtName', response.data[0].courtName);
        console.log('✅ Court ID saved: ' + response.data[0].id);
    }
}

### Notes

* Used to retrieve all available courts.
* First court ID is stored in environment for chaining with other booking APIs.
