# Session Management API Documentation

## Base URL
`https://devops.juaracoding.com/kelompok2/api/v1/auth`

---

## 4.3 Refresh Token

**Endpoint:** `POST /refresh-token`

**Description:**
Obtains a new access token using a valid refresh token. This endpoint is called when the current access token expires, allowing users to stay logged in without re-entering credentials.

---
