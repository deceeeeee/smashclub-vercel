# 4.3.1 Cancel Transaction by Reference [POSITIVE]

**Method:** `POST`
**Endpoint:** `https://devops.juaracoding.com/kelompok2/api/v1/transaction/cancel-by-reference/{{referenceCode}}`

**Description:** Cancel transaction by reference

**Response:**
```json
 {
"transactionCode": "",
"requested": true,
"totalPrice": 0.0,
"referenceCode": "",
"user": { "userId": "", "email": "", "fullName": "" }
}
```
