# Authentication API Documentation

## Base URL
`https://devops.juaracoding.com/kelompok2/api/v1/auth/login`

---

## 3.6 Resend OTP

**Endpoint:** `POST /resend-otp`

**Description:**
Resends a new One-Time Password (OTP) to the user's email when the previous OTP has expired or was not received.

---

### Request (application/json)
```json
{
    "userId": "644b6ad5-8ff0-44c9-99c5-31517548b927"
}

success response:
{
    "success": true,
    "message": "OTP resent successfully",
    "data": {
        "otpExpiry": 300,
        "attemptsRemaining": 3
    }
}

error response too many requests:
{
    "success": false,
    "error": "Too many requests",
    "message": "Please wait 60 seconds before requesting a new OTP"
}

error response user not found:
{
    "success": false,
    "error": "User not found",
    "message": "Invalid user ID"
}
