### Validation (Postman Tests)

* Response status must be 200
* `response.data` must be an array
* Each court should contain `availableSlots` array

---

## Example Test Script

```javascript
pm.test('Status code is 200', function() {
    pm.response.to.have.status(200);
});

pm.test('Each court has availableSlots', function() {
    const response = pm.response.json();
    pm.expect(response.data).to.be.an('array');
    if (response.data.length > 0) {
        pm.expect(response.data[0].availableSlots).to.be.an('array');
    }
});
```

* Used to check availability of all courts for a specific date.
