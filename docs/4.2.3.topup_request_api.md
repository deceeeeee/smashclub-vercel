# 4.2.3 Topup Request API

**Method:** `POST`
**Endpoint:** `https://devops.juaracoding.com/kelompok2/api/v1/wallet/balance/topup`

**Description:** Topup wallet

**Request Body:**
```json
{
    "amount": 200000
}
```

**Response:**
```json
{
    "data": {
        "transactionCode": "",
        "paymentData": {
            "invoiceUrl": ""
        }
    },
    "success": true,
    "message": "Topup request created!",
    "status": 200,
    "timestamp": "2026-02-23T12:34:00.403127493Z"
}
```
