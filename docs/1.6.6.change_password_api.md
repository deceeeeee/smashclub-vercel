# 6.6 Change Password

Base URL:
'https://devops.juaracoding.com/kelompok2/api/v1/profile/change-password'

---

## Overview

This endpoint allows an authenticated user to change their password.

The user must provide:
- currentPassword
- newPassword
- confirmPassword

This is a protected endpoint and requires a valid access token.

---

## Endpoint

POST /profile/change-password

---

## Headers

Authorization: Bearer <accessToken>
Content-Type: application/json

---

## Request Body

```json
{
  "currentPassword": "Password123",
  "newPassword": "NewPassword456",
  "confirmPassword": "NewPassword456"
}

| Field           | Type   | Required | Description             |
| --------------- | ------ | -------- | ----------------------- |
| currentPassword | string | Yes      | User's current password |
| newPassword     | string | Yes      | New password            |
| confirmPassword | string | Yes      | Must match newPassword  |

success response:
{
  "status": "success",
  "message": "Password changed successfully"
}

error response:
{
  "status": "error",
  "message": "Current password is incorrect"
}

unauthorized response:
{
  "status": "error",
  "message": "Unauthorized"
}
