## 3.5 Verify OTP - Wrong OTP

**Endpoint:** `POST /verify-otp`

**Description:**
Tests error handling when an incorrect OTP is entered during verification.

---

### Request (application/json)
```json
{
    "userId": "644b6ad5-8ff0-44c9-99c5-31517548b927",
    "otp": "999999"
}

error response:
{
    "success": false,
    "error": "Invalid OTP",
    "message": "The OTP you entered is incorrect"
}
