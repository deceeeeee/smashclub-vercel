## 3.2 Login with Wrong Password

**Endpoint:** `POST /login`

**Description:** 
Tests authentication failure when an incorrect password is provided.

---

### Request (application/json)
```json
{
    "email": "elvianavictoria@example.com",
    "password": "NewPassword1234"
}

error response:
{
    "success": false,
    "error": "Invalid credentials",
    "message": "Email or password is incorrect"
}
