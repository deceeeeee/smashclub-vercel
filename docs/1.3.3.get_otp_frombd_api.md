## 3.3 Get OTP from DB (for testing only)

**Endpoint:** `GET /test/get-otp`

**Description:** 
Retrieves the One-Time Password (OTP) associated with a user for testing purposes only.

⚠️ This endpoint must NOT be enabled in production.

---

### Query Parameters

| Parameter | Type   | Required | Description |
|-----------|--------|----------|------------|
| userId    | string | ✅ Yes   | User unique identifier |

---

### Example Request
GET /test/get-otp?userId=uuid


---

### Success Response (200 OK)
```json
{
    "success": true,
    "data": {
        "userId": "uuid",
        "otp": "482931",
        "expiresAt": "2026-02-16T12:30:00Z"
    }
}

error response:
{
    "success": false,
    "error": "OTP not found",
    "message": "No active OTP found for this user"
}
