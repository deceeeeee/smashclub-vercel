# 9.2 Cancel Already Cancelled Booking [NEGATIVE]

**Method:** `PUT`
**Endpoint:** `https://devops.juaracoding.com/kelompok2/api/v1/booking/{{bookingCode}}/status`

**Description:** Cancel already cancelled booking

**Request Body:**
```json
{
  "status": 0,
  "cancellationReason": "Try cancel again"
}
```

**Response:**
```json
{
    "detail": "Method 'PUT' is not supported.",
    "instance": "/api/v1/booking/status",
    "status": 405,
    "title": "Method Not Allowed"
}
```
