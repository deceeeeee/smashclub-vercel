# 6.2 Update Profile – Full Name Only

Base URL:
'https://devops.juaracoding.com/kelompok2/api/v1/auth'

---

## Overview

This endpoint updates the authenticated user's full name.

This is a protected endpoint and requires a valid access token.

Only the fullName field can be updated.

---

## Endpoint

PUT /profile

---

## Headers

Authorization: Bearer <accessToken>
Content-Type: application/json

---

## Request Body

```json
{
  "fullName": "Elviana Victoria Updated"
}

success response:
{
  "status": "success",
  "message": "Profile updated successfully",
  "data": {
    "id": 1,
    "fullName": "Elviana Victoria Updated",
    "email": "user@example.com",
    "role": "USER"
  }
}

error response:
{
  "status": "error",
  "message": "Unauthorized"
}

possible error response:
{
  "status": "error",
  "message": "Full name cannot be empty"
}
