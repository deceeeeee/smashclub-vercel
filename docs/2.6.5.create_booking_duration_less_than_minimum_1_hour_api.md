# 6.5 Create Booking - Duration Less Than Minimum 1 Hour [NEGATIVE]

**Method:** `POST`
**Endpoint:** `https://devops.juaracoding.com/kelompok2/api/v1/booking`

**Description:** Create booking with duration less than minimum 1 hour

**Request Body:**
```json
{
  "courtId": {{courtId}},
  "bookingDate": "{{date}}",
  "startTime": "09:00:00",
  "endTime": "09:30:00"
}
```

**Response:**
```json
{
    "path": "/api/v1/booking",
    "data": "",
    "success": false,
    "errorCode": "X01001",
    "message": "Unauthenticated",
    "status": 401,
    "timestamp": "2026-02-19T19:05:07.731786172Z"
}
```
