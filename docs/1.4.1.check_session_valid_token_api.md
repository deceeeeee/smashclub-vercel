# Session Management API Documentation

## Base URL
`https://devops.juaracoding.com/kelompok2/api/v1/auth`

---

## 4.1 Check Session (Valid Token)

**Endpoint:** `GET /check-session`

**Description:**
Validates the current user session and returns user information if the token is valid. Used to verify authentication status on app load or protected route access.

---

### Headers

### Request
GET /check-session


### Success Response
```json
{
    "success": true,
    "data": {
        "authenticated": true,
        "user": {
            "id": "644b6ad5-8ff0-44c9-99c5-31517548b927",
            "email": "user@example.com",
            "name": "John Doe",
            "role": "user",
            "verified": true
        },
        "sessionId": "sess_123xyz",
        "expiresAt": "2024-01-01T13:00:00Z"
    }
}

error response invalid token:
{
    "success": false,
    "error": "Invalid or expired token",
    "message": "Please login again"
}

error response no token:
{
    "success": false,
    "error": "Unauthorized",
    "message": "No token provided"
}
