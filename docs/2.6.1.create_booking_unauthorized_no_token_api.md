# 6.1 Create Booking - Unauthorised (No Token) [NEGATIVE]

**Method:** `POST`
**Endpoint:** `https://devops.juaracoding.com/kelompok2/api/v1/booking`

**Description:** Create booking with no token

**Request Body:**
```json
{
  "courtId": {{courtId}},
  "bookingDate": "{{date}}",
  "startTime": "{{startTime}}",
  "endTime": "{{endTime}}"
}
```

**Response:**
```json
{
    "path": "/api/v1/booking",
    "data": "",
    "success": false,
    "errorCode": "X01001",
    "message": "Unauthenticated",
    "status": 401,
    "timestamp": "2026-02-19T18:46:25.530748766Z"
}
```
