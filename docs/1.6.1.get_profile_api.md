# 6.1 Get Profile

Base URL:
'https://devops.juaracoding.com/kelompok2/api/v1/auth'

---

## Overview

This endpoint retrieves the authenticated user's profile information.

This is a protected endpoint and requires a valid access token.

---

## Endpoint

GET /profile

---

## Headers

Authorization: Bearer <accessToken>
Content-Type: application/json

---

## Authentication

This endpoint requires a valid JWT access token.

If token is missing or invalid → API should return 401 Unauthorized.

---

## Example Request

GET /profile

Headers:
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

---

## Success Response (200)

```json
{
  "status": "success",
  "data": {
    "id": 1,
    "name": "John Doe",
    "email": "john.doe@example.com",
    "role": "USER",
    "createdAt": "2024-01-10T10:30:00Z"
  }
}

error response:
{
  "status": "error",
  "message": "Unauthorized"
}
